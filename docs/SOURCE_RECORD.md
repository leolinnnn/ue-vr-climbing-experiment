## Prototype and experiment versions

The original asset timestamps place the available custom UE prototype on
12–13 April 2025. The thesis and final presentation document a later experiment.
The final scoring Blueprint and four final experiment maps have not yet been
located. Searching autosaves did not identify a matching final asset.

The available C++ files contain a module declaration and an empty `MyClass`
constructor/destructor. Most other C++ files in the supplied folders belong to
VR Expansion/OpenXR Expansion. They are third-party implementation dependencies.

## Repository preparation

The Markdown documentation, manifest and Python inspection utility were added
for this archive in November 2026. They explain and check the retained materials;
they are not presented as code executed during the 2025 experiment.

The thesis reports 20 recruited participants. Its narrative statistics and
displayed tables contain discrepancies, so this implementation archive does not
publish a new inferential analysis or adopt the disputed numerical conclusions.
Participant-level records and identifiable experiment photographs are not part
of this source package.
